# Лабораторна робота №8 — Study Planner

Клієнтський застосунок на React і TypeScript для планування навчальних завдань.

## Запуск

```sh
npm install
npm run dev
```

Щоб відкрити лабораторну подвійним клацанням з `Typescript/index.html`, зберіть її
один раз командою `npm run build`. Застосунок збирається в один HTML-файл
`dist/index.html` і працює без локального сервера.

## Перевірки

```sh
npm run lint
npm run build
```

## Реалізовано

- компонентна структура: Header, TaskForm, TaskFilters, TaskList, TaskItem і TaskStats;
- створення, виконання та видалення завдань через immutable updates;
- фільтри «Усі», «Активні» та «Виконані»;
- статистика і повідомлення для порожнього результату.

Стан зберігається у пам’яті React і після перезавантаження починається з початкового списку.
