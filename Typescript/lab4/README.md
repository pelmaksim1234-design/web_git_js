# Лабораторна робота №4 — лотерея учасників

Застосунок на Vue 3, Composition API та TypeScript.

## Запуск

```sh
npm install
npm run dev
```

Перевірки перед здачею:

```sh
npm run type-check
npm run lint
npm run build
```

Учасники зберігаються у `localStorage` браузера. Форма перевіряє обов'язкові поля, дату народження, унікальність електронної пошти та український номер телефону `+380XXXXXXXXX`. Список можна шукати, сортувати, редагувати й видаляти; учасник не може бути обраний переможцем двічі, а список переможців обмежено трьома записами.
