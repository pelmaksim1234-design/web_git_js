# Лабораторна робота №9 — Study Planner

Продовження планувальника навчальних завдань із лабораторної №8: стан завдань керується `useReducer` та доступний через Context API. Зміни зберігаються в `localStorage`, редагування і видалення супроводжуються Toast-повідомленнями.

## Запуск

```sh
npm install
npm run dev
```

Щоб відкрити лабораторну подвійним клацанням з `Typescript/index.html`, зберіть її
один раз командою `npm run build`. Застосунок збирається в один HTML-файл
`dist/index.html` і працює без локального сервера.

## Перевірки

```sh
npm run lint
npm run build
```

## Реалізовано

- додавання, редагування, фільтрація, позначення виконаних і скидання завдань;
- Context API та чистий reducer з типізованими actions;
- збереження задач і активного фільтра між перезавантаженнями;
- власні hooks `useTaskContext` та `useLocalStorage`;
- видалення з 5-секундним таймером, індикатором прогресу й можливістю скасування;
- Toast-повідомлення та синхронізація заголовка вкладки з кількістю активних задач.

Незавершене видалення діє лише в поточній сесії; після перезавантаження збережене завдання повертається до звичайного списку.
